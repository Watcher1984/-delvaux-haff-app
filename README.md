# Delvaux's Haff

GitHub-fertige mobile Hof-App.

## GitHub Upload
1. Neues Repository `delvaux-haff-app` erstellen.
2. ZIP entpacken.
3. Den **Inhalt** des Ordners hochladen, nicht die ZIP selbst.
4. Branch `main` verwenden.
5. Repository → Settings → Pages.
6. Source auf **GitHub Actions** stellen.
7. Unter Actions den erfolgreichen Deploy abwarten.
8. Settings → Pages zeigt die App-Adresse.

## iPhone
App-Adresse in Safari öffnen → Teilen → Zum Home-Bildschirm → Hinzufügen.

Die aktuelle Version speichert Daten lokal auf dem jeweiligen Gerät.
